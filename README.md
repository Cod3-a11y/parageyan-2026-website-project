Parageyan 2026 — Event Website

A website for Parageyan 2026 at Basilan State College, developed as part of a second-year BSIT web development activity.

The website presents information about the celebration, its activities, event schedule, and memorable moments through a blue-and-white interface.

Features

- Home Section — Introduces Parageyan 2026 with the tagline Culture. Talent. Unity. Excellence.
- About Section — Presents information about the event and its celebration.
- Activities Section — Highlights featured activities and events.
- Schedule Section — Displays the event schedule for October 3–7, 2026.
- Gallery Section — Showcases photographs of Parageyan activities, including an Indigenous Tribe float, field demonstrations, and a Taekwondo competition.
- Navigation Menu — Provides links to the website's main sections.
- Responsive Styling — Uses CSS to help the layout adapt to different screen sizes.

Technologies Used

- HTML5 — Website structure and content.
- CSS3 — Styling, layout, and visual presentation.
- JavaScript — Interactive website functionality.

How to Run Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Navigate through the website sections to explore the event information.

Project Files

- "index.html" — Main website structure and content.
- "ParageyanStyle.css" — Website styling and layout.
- "ParageyanScript.js" — JavaScript functionality.
- "28/" — Repository folder currently associated with the project; verify that it contains the intended image assets before relying on this folder name.

Purpose

This project demonstrates the use of HTML, CSS, and JavaScript to create an event website that organizes information, presents a schedule, and showcases photographs in a navigable interface.
